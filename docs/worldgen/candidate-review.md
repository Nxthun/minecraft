# NxTerra additional worldgen candidates

Modrinth versions and licenses were checked for NeoForge 1.21.1. The primary files were downloaded for inspection and checked against Modrinth's SHA-512. Embedded NeoForge dependency ranges take precedence when they conflict with listing metadata. These static results identify likely overlap and load blockers. Runtime and generation evidence appears in the build report.

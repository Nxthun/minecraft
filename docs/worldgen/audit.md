# NxTerra worldgen audit

The baseline is the archived main server under `nxterra-dev/main/server/` in `Altair-nxterra-dev.zip`, the local published pack at `8518846`, and the matching Minecraft 1.21.1 vanilla resources. The archived server, published pack and extras have byte-identical Structurify configuration. The inventories cover static resources and snapshot settings. Runtime registration, pack precedence, hard-coded structures and measured spawn density need a copied-server baseline. The inventory covers 300 set IDs, including one disabled optional built-in set, and 960 loot IDs. The placement-config inventory adds 279 settings rows from 118 files.

- [Structure inventory](structure-inventory.md) lists structure sets by resource ID, raw placement, Structurify values, weights, exclusion rules and duplicate sources. It also links structure definitions to reachable jigsaw templates and chest tables.
- [Placement configs](placement-configs.md) records Cristel Lib, vanilla and Towns and Towers placement settings, YUNG's replacement switches, and relevant CTOV, Dimensional Dungeons and Ice and Fire settings.
- [Loot inventory](loot-inventory.md) records referenced and candidate structure loot tables, shipped item entries, nested links and editorial tiers. It marks unresolved tables for the copied-server check.
- [Proposal](proposal.md) is the loot and mod approval request.

## Findings

1. Selective scarcity is already built into the pack. The 0.8 global Structurify multiplier has 92 set exemptions, 10 with explicit spacing and separation. Cataclysm’s Ancient Factory remains 112/70, Sunken City remains 100/70, and The Graveyard’s Lich Prison remains 120/100. In Dungeons and Taverns, the Shrine Tower goes from 600/312 to an estimated 480/249 with the global modifier, a 7.68 km candidate grid before biome and stronghold exclusions. Illager Hideout and Trident Trial Monument each start at 200 chunks and have an estimated 160-chunk grid. The monument also has a narrow candidate offset and restricted biomes. Those settings can explain sparse landmarks without implying that any specific seed lacks them.
2. Shared sets and replacement layers affect which landmarks appear. The Dungeons and Taverns version of the mansion set gives vanilla Mansion and Illager Manor equal weight in one placement set. Nature's Spirit puts four of its villages into the vanilla village set. CTOV favors small, medium and large villages with weights 10:4:1 and supplies conditional additions to jigsaw pools. In the archive, Towns and Towers specifies 51/12 for towns, while Structurify requests 32/12. Confirm effective runtime ordering before editing overlapping settings.
3. YUNG’s snapshot config switches off vanilla pyramids, mineshafts, jungle temples, witch huts, ocean monuments and Nether fortresses. Their vanilla registry resources remain visible in the inventory. The Better Strongholds ruin option is also off. No explicit false structure entries appeared in the parsed Cristel Lib, vanilla or Towns and Towers toggle files. Aether’s optional ruined-portal pack is disabled in the snapshot.
4. Global overlap prevention is already enabled. The explicit flatness checks in Structurify cover five vanilla villages and the vanilla pillager outpost. The first terrain pass should target large-footprint structures using biome and height restrictions, footprint checks and appropriate terrain adaptation. Preserve Lithosphere and the existing KubeJS density overrides while checking whether the archived Still Life noise resource affects the runtime winner.
5. The pack already ships high-value tables, including Ancient City rewards, alongside much lighter pools such as the Welcome Camp. Shared tables can reward unrelated structures together. The rare and epic distance rolls should target selected structure-specific chests and be checked with Lootr. Item tiers in the inventory are based on possible explicit entries and do not establish expected value or drop rates.

6. The shipped Dungeons and Taverns Illager Manor basement pool contains a bare processor ID that fails the static JSON scan. The loot inventory also marks 59 IDs with no matching definition in the scanned resources. Some belong to optional integrations. Check the basement pool and direct references used by enabled structures on the test copy before treating them as defects or changing loot.

## Copied-server baseline after approval

Dump active packs and StructureSet values before changing placement. Resolve conditional template pools, hard-coded containers and unresolved loot IDs on the test copy. For the same seeds and generated regions, count structure starts by type and band, compare cliff placements, and record tick time and peak memory. Keep a fallthrough baseline when modifying shared loot or layered placement configs so changes can be attributed to the intended setting.
